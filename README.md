# Titanic Survival Dashboard

## Project Overview
This project is an interactive dashboard that analyses Titanic passenger data. It helps users understand survival patterns based on gender, passenger class and age.

## Dataset
The dataset was downloaded from Kaggle.

- Dataset: Titanic Dataset
- File used: `train.csv`
- Total passengers: 891
- Total survivors: 342
- Total deaths: 549

## Dashboard Features

The dashboard includes:

1. **Overall Survival:** Shows the number and percentage of passengers who survived and died.
2. **Survival by Gender:** Compares male and female survival.
3. **Survival by Passenger Class:** Shows survival patterns across first, second and third class.
4. **Age Distribution:** Compares the ages of passengers who survived and died.
5. **Passenger Class Filter:** Allows users to select different passenger classes.

## How to Run the Project

1. Download or clone this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the dashboard:

   `streamlit run app.py`
